# הערכת Mac mini A1347 מחודש
2026-11-24; מחקר בלבד. מחיר מדווח 720 ש״ח; i7/16GB/512GB SSD לפי המשתמש וכתובת המוצר. דף החנות חסום בבדיקת JavaScript ולכן שנתון, אחריות, מלאי ומחיר לא אומתו.
A1347 כולל מספר דורות: 2012 i7 ארבע ליבות, macOS Catalina; 2014 i7 שתי ליבות, macOS Monterey. קיימים גם דורות ישנים יותר. יש לקבל Model Identifier, CPU מדויק ו-EMC. דגם 2012 מפרט תצוגה רשמי 2560x1600 Mini DisplayPort; אין להניח תמיכה במסך 34UW 3440x1440 בקצב הרצוי. Gigabit Ethernet. מערכות macOS ישנות אינן בחירה טובה לתחנת עבודה חשופה לאינטרנט; Linux נתמך עשוי להתאים לאחר אימות סינון ותאימות. SSH/RDP/דשבורד אפשריים בכפוף לתוכנה נתמכת. לא מומלץ כתחנה מרכזית ארוכת טווח. להשוות Mac mini M1 משומש, M4, OptiPlex Micro/ThinkCentre Tiny דור 8 ומעלה ו-N100/N150; מחירי חלופות לא נבדקו. לא לרכוש לפני אימות מסך, אחריות, מצב SSD, שנתון וסינון.
